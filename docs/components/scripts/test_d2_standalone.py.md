# scripts/test_d2_standalone.py

## Áttekintés

Ez a standalone teszt script a D02SupportProcessor közvetlen tesztelésére szolgál, megkerülve a UI és Service rétegeket. A script inicializálja a core komponenseket, betölti a tick adatokat, átalakítja H1 OHLCV gyertyákká, majd futtatja a D2 Support Processor-t.

**Verzió:** 1.0.0
**Cél:** Diagnosztikai eszköz a D2 dimenzió processzorának gyors teszteléséhez

## Fő jellemzők

- **Standalone mód:** Közvetlen processzor tesztelés core bootstrap-pel
- **Tick adat betöltés:** Automatikus adatbetöltés az adatbázisból
- **H1 resample:** Tick adatok átalakítása órás gyertyákká
- **Swing pont detektálás:** Support/Resistance szintek azonosítása
- **Diagnosztikai kimenet:** Részletes eredmények kiírása konzolra

## Használat

```bash
python scripts/test_d2_standalone.py
```

### Paraméterek

A script jelenleg fix paraméterekkel fut:
- **Szimbólum:** EURUSD
- **Időtartomány:** 2023-01-01 - 2023-01-02 (UTC)

## Architektúra

### Fő komponensek

1. **Bootstrap Core:** A rendszer inicializálása a core komponensekkel (config, logger, storage)
2. **Tick Adat Betöltés:** `core.storage.read_tick_data()` használata
3. **ResamplerService:** Tick adatok H1 OHLCV gyertyákká alakítása
4. **D02SupportFactory:** Support/Resistance processzor példányosítása
5. **Diagnosztika:** Eredmények elemzése és kiírása

### Feldolgozási folyamat

```python
# 1. Core inicializálás
core = bootstrap_core()

# 2. Tick adatok betöltése
df = await core.storage.read_tick_data("EURUSD", start_date, end_date)

# 3. H1 resample (privát metódus használata teszt célból)
resampler = ResamplerServiceFactory.create(core.storage)
ohlcv = resampler._convert_to_ohlcv(df, "1h")

# 4. OHLCV adatok transzformálása
ohlcv = ohlcv.with_columns(
    high=pl.col("bid_high"),
    low=pl.col("bid_low"),
    open=pl.col("bid_open"),
    close=pl.col("bid_close"),
)

# 5. D2 Processor futtatása
processor = D02SupportFactory.create(core.config, core.logger)
result = processor.process(ohlcv, timeframe="H1")
```

## Kimenet formátum

### Diagnosztikai adatok

A script a következő információkat írja ki:

1. **Oszlop lista:** Az eredmény DataFrame összes oszlopa
2. **Swing pont számlálók:**
   - Swing High Body: Body rész swing high pontjainak száma
   - Swing Low Body: Body rész swing low pontjainak száma
   - Swing High Wick: Wick rész swing high pontjainak száma
   - Swing Low Wick: Wick rész swing low pontjainak száma
3. **Minták:** Az első 5 swing ponttal rendelkező sor megjelenítése
